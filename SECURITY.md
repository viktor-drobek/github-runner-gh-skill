# Security policy

## Supported release

Security fixes are made on the latest release line.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository. Do not open a public issue for suspected token exposure, credential handling failures, or runner compromise.

Include a minimal reproduction and the affected version. Do not include live tokens, registration files, credentials, or private repository data. Replace them with placeholders.

## Scope

Reports are especially useful for issues involving token handoff, GitHub permission checks, runner registration or removal, and command injection. The repository intentionally contains no runtime image definitions or build recipes.
